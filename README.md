# AFKraft Companion

Multi-version companion mod for AFKraft supporting **Fabric** and **NeoForge** across 16 Minecraft versions (10 Stonecutter nodes from 1.21.1 to 26.3).

## Documentation & Maintainer Guides

- [**RELEASING.md**](./RELEASING.md) — Operational runbook for version bumps, `update.json` governance, and publishing releases.
- [**VERSIONING.md**](./VERSIONING.md) — Multi-version guide and runbook for porting to new Minecraft releases.
- [**ADAPTERS.md**](./ADAPTERS.md) — Architecture decision matrix and catalog of Minecraft version adapters and Loader SPIs.

## Setup

For setup instructions, please see the [Fabric Documentation page](https://docs.fabricmc.net/develop/getting-started/creating-a-project#setting-up) related to the IDE that you are using.
